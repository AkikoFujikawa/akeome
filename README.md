# Birthday Card

### 4言語で気持ちを伝えるバースデーカード

Web開発の学習初期に、HTML・CSSの基礎を学びながら制作した  
オリジナルのバースデーカードです。

日本語・中国語（繁体字）・ミャンマー語・英語を取り入れ、  
Webページとして誕生日のお祝いを届けられるように制作しました。

##  公開ページ

 [Birthday Cardを見る](https://akikofujikawa.github.io/akeome/)

---

##  About

誕生日のお祝いメッセージを、  
画像とテキストを組み合わせたWebページとして制作しました。

実際に相手へ気持ちを届けることを目的に、  
見やすさや親しみやすさを意識してデザインしています。

また、相手に合わせて複数の言語を取り入れ、  
日本語だけではない表現にも挑戦しました。

---

##  使用した言語

- 日本語
- 中国語（繁体字）
- ミャンマー語
- 英語

---

##  工夫したこと

- 画像とメッセージをカード型のレイアウトに配置
- 4言語を組み合わせたメッセージ表現
- 背景色や文字色、余白を調整して読みやすくデザイン
- `border-radius` や `box-shadow` を使用したカード表現
- スマートフォンでも見やすいようにレスポンシブ対応
- 画像が画面幅に合わせて自然に表示されるよう調整

---

##  使用技術

HTML / CSS / GitHub Pages

---

##  学んだこと

この制作を通して、HTMLによるページ構成やCSSによる装飾、  
レイアウト、画像表示、レスポンシブデザインなど、  
Webページ制作の基礎を学びました。

また、単にコードを書くのではなく、  
**「誰に、どんな気持ちを、どのように届けるか」**を考えながら制作する経験にもなりました。

小さな作品ですが、  
学んだ技術を使って、実際に誰かに届けるものを形にした制作物です。
